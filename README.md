# 📁 Gerenciador de Arquivos & Pastas Local

Aplicação web desenvolvida para gerenciar diretórios e arquivos de forma integrada com o sistema de arquivos local do sistema operacional através do navegador.

## 🚀 Tecnologias Utilizadas
* **HTML5 Semântico**
* **CSS3** (Flexbox e design moderno)
* **JavaScript (ES6+)**
* **File System Access API** (Integração nativa com o disco rígido)

## 💡 Funcionalidades
* Seleção de diretórios reais do computador (`window.showDirectoryPicker()`).
* Navegação em árvore de subpastas e retorno ao diretório pai.
* Criação em tempo real de novas pastas e arquivos diretamente no disco rígido.
* Leitura de conteúdo de arquivos de texto locais.
